推荐做法 (3 分钟)

  1. 1. 回到运行服务的终端，停掉服务后执行： 
    npm run setup

    交互向导会问你选哪家、粘贴一次 API key，自动写入 .env。

  2. 2. 重启服务： 
    npm start
  3. 3. 回到 首页 注册账号 → 创建角色 → 开聊。

或者：手动编辑 .env

如果服务不在你能开终端的机器上（比如远程容器），可以手动改 .env 文件然后重启：

CHAT_PROVIDER=deepseek
DEEPSEEK_API_KEY=your_deepseek_api_key_here

安全提示

  • · 本页 不会 在浏览器里写 .env —— 凭据必须落在你能访问的文件系统上才安全。
  • · .env 已在 .gitignore。永远不要把它 commit 进仓库。
  • · 部署到公网时记得用 nginx / Caddy 加 TLS，参考 deploy/nginx.conf.example。
