## 第一部分 · 评审约束（维护者已拍板，设计稿不满足即打回）

### 生产证据（为什么这四条是硬约束）

2026-06-12 生产实锤：她声称在看的书《她总在转角处等我》——**用户实搜无此书**，
纯属 LLM 虚构。叠加更早的案例（书名每次问每次变、封面照拍不出），current_works
的"真实性"不是锦上添花，是这个特性能不能立住的地基。

### 约束 1：书/剧/番类条目必须真实存在（生成时搜索验证）

- current_works 生成"她在看的书/剧/番"时，**先用搜索 provider 验证
  「作品名 + 作者/出品方」真实存在，验证通过才入档**；她的台词只许说
  档案里的作品名，绝不现编。
- 接入点：现成 `web_search.mjs::webSearch(query)`（Tavily），生成侧调
  `webSearch("《作品名》 作者名 书")`，结果 snippet 含该名+作者即过。
- 成本评估：每次换书/换剧一次搜索调用——档案生命周期是天～周级，
  调用频率 ≈ 每 companion 每周 1-3 次，可忽略。**搜不到→重新生成换一部**，
  重试 2 次仍失败则该周期降级为"不指名的泛读状态"（"最近在看一本推理小说"），
  绝不带着虚构名入档。
- 验证失败必须响：`[CurrentWorks] 作品验证失败` 走 warn 日志；连续失败
  说明 search provider 挂了，digest 错误签名段可见。

### 约束 2：封面照双坑规避（伪造 vs 版权）——一律 POV 内页/书脊

- 真书封面：**生成 = 伪造**（图片模型画不出真封面，画出来就是假货穿帮）、
  **复刻 = 版权**（即使画得像也是侵权复制）。两条路都死。
- 解法：书/剧/番类场景照**一律 ACTIVITY-POV 机位**（photo_planner 现成
  shotMode）——拍摊开的内页、书脊一角、压在书上的手；**标题最多露半截**
  （imagePrompt 明令 partial/cropped title, never full readable cover）。
  剧/番同理：拍"屏幕一角+沙发毯子"的氛围，不拍可识别的版权画面。
- planner prompt 加确定性约束行（同月相事实注入的写法），不靠 LLM 自觉。

### 约束 3：存量虚构作品名退场——生命周期自然完结，不回溯清洗

- 历史对话/记忆里已存在的虚构书名（如《她总在转角处等我》）**不做数据清洗**
  ——她提过的书突然消失同样穿帮，且对话历史是史实（#279 同款纪律）。
- 退场路径：靠 current_works 档案生命周期自然完结——上线后她"那本看完啦，
  最近换了本新的"，新书从真实档案出。旧虚构名随着话题自然沉底。
- 若用户主动追问旧虚构书（"你之前说的那本转角呢"）：她按"看完了"语义接，
  不展开内容细节（展开=继续虚构）。这条进设计稿的表达层约束。

### 约束 4：现实世界锚定正式纳入设计范围（同族约束统一设计）

current_works 是"她的世界要经得起现实查证"这族问题的一员，与天象/天气/节日
同族。统一为**现实事实注入层**（reality facts），proactive 与 photo_planner
共用一个注入口（已有先例：月相注入点就在这两处）。

| 锚定项 | 状态 | 实现路径 | 成本 |
|---|---|---|---|
| 月相 | ✅ 已落地（v1.21.5，`src/utils/moon_phase.mjs`） | 朔望月纯数学，照亮比例/相名/前半夜可见性 | 零（纯计算） |
| 节气 | 设计稿内实现 | 24 节气查表（2026-2030 五年表 ≈120 行常量）或太阳黄经近似式；`solar_terms.mjs` 同 utils 族 | 零（查表/纯计算） |
| 节日 | 设计稿内实现 | 公历节日查表 + 农历节日（春节/中秋等）2026-2030 五年对照表；已有 reminders 的 holiday 类可对齐复用 | 零（查表） |
| 天气 | 可选项，默认不接 | 需外部 API（心知/和风/OpenWeather，free tier 够用）+ 城市定位（她的人设城市，非用户定位）；**未配 key 时降级为"不提具体天气"**——宁可不说，不许编 | 一个 key + 每日 ~24 次调用 |
| 作品存在性 | 本稿约束 1 | webSearch 验证后入档 | 每周 1-3 次搜索 |

- 统一原则（从月相 PR 沿用）："**文书引用机制不引用常量**"的姊妹版——
  **prompt 引用事实层，不引用猜测**；事实层拿不到数据时降级为"不提"，
  绝不让 LLM 补位瞎编。
- 注入形态统一：`【★ 真实世界】今天：{节气}，{节日}；今晚月相：{相名}…`
  一行事实，夜间/相关场景才注入（同月相的"白天零开销"原则）。
